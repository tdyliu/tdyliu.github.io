Projects

Things I've built.

1
ESP32 Remote Wake Switch
PCB Design Embedded Fusion 360 3D Printing
Designed and fabricated a custom PCB to interface with an ESP32 microcontroller, enabling remote PC power control over a home network or network tunnel like tailscale. Programmed embedded firmware to handle wake signals and designed a fitted enclosure in Fusion 360, printed on my personal 3D printer. The project covered the full development cycle from schematic to finished physical device.
2
Headless Home Linux Server
Linux Docker Networking Server Admin
Deployed a headless Linux server on a refurbished Dell OptiPlex to host game servers and cloud storage. Configured playit.gg tunnels to expose services publicly, bypassing carrier-grade NAT (CGNAT) without port forwarding. Managed via CLI and self-hosted web interfaces.
3
Equatorial Telescope Mount Tracker
Embedded Fusion 360 3D Printing Mechatronics Power Electronics
Built a motorized RA drive for an equatorial telescope mount using a WeMos D1 R32 and CNC Shield V3 running OnStepX firmware, with TMC2209 stepper drivers for quiet, precise tracking. Designed a GT2 belt reduction (3:1) for the RA axis and a portable 12V power stage — USB-C PD triggered via a ZY12PDN buck converter off a 10000mAh battery bank — for fully off-grid GoTo tracking.
