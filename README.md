# tdyliu.github.io

Personal portfolio website for Teddy Liu — Aerospace & Mechanical Engineering student at UC Davis (Class of 2027).

**Live site:** [tdyliu.github.io](https://tdyliu.github.io)

## About

A single-page portfolio covering my background, projects, work experience, and skills — built to showcase hands-on engineering work across CAD, embedded systems, 3D printing, and electromechanical builds.

## Tech Stack

- Vanilla HTML / CSS / JavaScript — no framework, no build step
- CSS custom properties for theming (light/dark mode toggle)
- [Bootstrap Icons](https://icons.getbootstrap.com/) for UI icons
- Google Fonts (Cormorant, Karla)
- Hosted on GitHub Pages

## Structure

```
├── index.html    # Page content and structure
├── style.css     # Styling, layout, and theme variables
├── script.js     # Theme toggle logic
└── resume.pdf    # Downloadable resume
```

## Features

- Light/dark theme toggle with `localStorage` persistence
- Scroll-triggered fade-in animations
- Fully responsive layout
